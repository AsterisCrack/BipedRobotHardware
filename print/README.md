# Print files

| Folder | Contents |
|---|---|
| [`stl/`](stl/) | One STL per part, already in print orientation |
| [`3mf/`](3mf/) | Optional: ready-made plates with slicer settings baked in |
| [`print_settings.md`](print_settings.md) | Material, layer height, infill, supports and per-part notes |

The full list of parts, quantities, material and print time is in
[`../bom/printed_parts.csv`](../bom/printed_parts.csv).
